# MuJoCo 真实 CAD 可视运动学检查点

## 工程结果

现有 EduLite 整机结构已经第一次成为可在 Linux 桌面实时观察和操作的 MuJoCo
模型。它不是 AI 重新想象的机器人外壳：视觉几何来自本仓库固定哈希的原遥想星空
总装 STEP、官方 EL05 STEP 和此前完成的左右 EduLite 支架/主动杆补丁。

![70/90/120 mm 三个姿态](../../artifacts/mujoco/visual_kinematic_checkpoint.png)

模型现在可以可靠回答“零件是否属于正确刚体、关节是否真实存在、五连杆是否闭合、
腿长变化是否与 Phase 3 一致”。它还不回答跳台阶，因为这一个检查点刻意先把
外观和运动拓扑做正确。

## CAD 到实时模型

FreeCAD 在 `90 mm` 基准姿态把装配拆成 22 个刚体视觉网格。原始 B-Rep 网格化后
约 `1,628,352` 个三角面；实时显示版本约 `368,412` 面。优化只作用于外观副本，
没有修改机械包络扫描使用的 STEP/B-Rep 几何。

MuJoCo 中使用两层几何：

- CAD OBJ：显示真实底板、支架、EL05、主动杆、被动杆、轴承、紧固件和轮系，
  设置为不参与碰撞；
- capsule/cylinder：表示连杆和轮子的简化碰撞层，可在控制面板中显示，但当前
  运动学检查模式默认关闭碰撞响应。

CAD 坐标通过 `MuJoCo xyz = CAD xzy / 1000` 转成米制、z 向上的仿真坐标；每个
活动网格再变换到自己的真实关节局部坐标。因此网格随刚体和关节运动，不是按每帧
重新摆放一组世界坐标模型。

## 真连接如何实现

每侧腿有：

- 两个主动髋部 hinge；
- 两个被动膝部 hinge；
- 一个轮子 hinge；
- 一个 `connect` 闭环约束，把第二支链末端与轮轴中心约束到同一点。

闭环点只限制两个端点的位置重合，仍允许被动杆和轮轴相对转动，符合平面五杆的
机械关系。黄色/蓝色闭环 site 可以在 Viewer 中观察；碰撞胶囊和关节轴也可以
单独打开。

## Phase 3 交叉验证

界面给定 `l0` 后，仍由 `normal_vertical_posture`/`cad_pose` 计算正常 outward-
elbow 分支，再把绝对关节角转换为 MuJoCo 相对关节坐标。不是用 Viewer 中的
视觉位置反推角度。

| 腿长 | 左右轮轴期望高度 | 最大闭环残差 |
|---:|---:|---:|
| 70 mm | 84 mm | `8.72e-9 mm` |
| 90 mm | 64 mm | `1.19e-8 mm` |
| 120 mm | 34 mm | `1.63e-8 mm` |

高度包含当前固定底盘的 `120 mm` Viewer 展示偏置；三个姿态的相对位移严格为
50 mm。残差来自 XML 小数输出精度，远小于 CAD 和加工精度。

## 可见界面

```bash
python3 scripts/run_mujoco_viewer.py
```

启动后同时打开 MuJoCo Viewer 和中文控制面板。当前可以：

- 连续拖动 `70--120 mm` 腿长；
- 跳转到 70/90/120 mm 基准姿态；
- 自动往复伸缩；
- 切换立体、正面和侧面相机；
- 显示简化碰撞体和关节轴；
- 实时读取 `phi1`、`phi4` 和左右闭环最大误差；
- 使用 MuJoCo 原生面板检查 equality、joint、渲染和模型数据。

重新从 STEP 生成全部视觉资产和 MJCF：

```bash
python3 scripts/prepare_mujoco_assets.py
```

该入口会自动把输入暂存到 snap FreeCAD 可访问的 Linux 用户目录，完成 B-Rep
网格化、实时面数优化和 MJCF 重建，然后删除准确限定的临时目录。源 STEP 哈希和
网格前后面数记录在 `mujoco/assets/manifest.json`。

## 现在真实到什么程度

**已验证**：真实 CAD 外观来源、刚体分组、关节拓扑、左右五连杆闭合、
70--120 mm 连续中心竖直运动、Phase 3 轮轴坐标一致性，以及桌面实时界面。

**尚未作为动力学证据**：当前底盘固定；质量、质心和惯量只是使模型可编译的
临时显式值；自碰撞和地面接触尚未放行；没有电机扭矩控制、平衡、台阶或落地
动作。因此当前模型好看且连接正确，但不能因为它能播放伸缩就称为越阶仿真。

## 下一检查点

下一步是在不改视觉模型的前提下完成动力学层：建立主要部件质量清单和 CAD 惯量、
释放底盘六自由度、放行经过审计的碰撞对、加入轮地摩擦与 EL05/轮端扭矩执行器，
先验证静态落地和腿长保持。只有该层稳定后，才放入 5/10/15 cm 台阶和动作状态机。
