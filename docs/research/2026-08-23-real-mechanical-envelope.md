# 遥想星空原结构真实机械包络：工程判定

## 结论先行

本工作包第一次把 Phase 3 的理想二维连续路径落实到遥想星空原始三维总装。
截至本次检查，证据支持以下判定：

- **已证明（当前 STEP 模型与扫描精度下）**：原结构 `70--120 mm` 的 51 个
  1 mm 姿态全部无实体互穿，也没有名义接触；最小非相邻间隙为
  `0.9849075 mm`，发生在 `l0=70 mm` 的 4010 电机与小腿之间。
- **已证明（边界样本）**：短端不是由 Jacobian 首先限制。`47--60.4 mm`
  存在主动短杆/垫高件与相连小腿的实体互穿；`60.5--67.70 mm` 虽已退出
  实体互穿，4010 电机与小腿仍为名义零间隙接触；`67.71 mm` 是首个正间隙
  样本，但间隙只有 `2.47e-5 mm`，没有任何工程裕度。
- **强证据**：从 `67.71 mm` 向长端到 `152 mm`，已检查样本均为正间隙。
  `152 mm` 的最小间隙仍有 `7.047 mm`；长端首先遇到的是
  `152.0691 mm` 的数学串联奇异，而不是当前 CAD 实体碰撞。
- **已证明**：EduLite 05 不能在保留原内部布局时原位直装。对齐原主动轴和
  输出安装面后，壳体与 NanoPi 支架、电池架及多根支撑柱发生穿透，最大单对
  交叠约 `77.16 mm³`；原 4010 支架和主动杆输出接口也不兼容。
- **必要条件通过、充分条件未知**：移除必然重做的四个支架、四个 4010、
  四块原腿电机驱动板和可重排的内部器件，只保留底板、五连杆和轮系时，
  EduLite 官方商品外形在 `70--120 mm` 的扫描中无碰撞。因为新支架、主动杆
  接口和线束 keep-out 尚未建模，这不能称为“EduLite 安装后已验证”。

因此原杆长继续 **KEEP**，`70--120 mm` 继续作为进入后续动力分析的候选真实
行程；EduLite 方向是 **CONDITIONAL KEEP**，但“直接替换”方案应判为
**REJECT**。在形成真实 EduLite 支架和接口 CAD 前仍然 **NOT YET** 进入执行器
或 150 mm 台阶动力学。

## 输入资格与可追溯性

用户提供的原总装 AP214 STEP 固定为：

```text
cdca79d8ed21ebf3462d4d65d81c4d7696d988069e280445a09181b2856e37c4
```

FreeCAD 1.1.1/OpenCascade 导入结果为 80 个有效实体、0 个无效实体、总包围盒
`211.0 x 136.4469 x 178.3510 mm`。80 个实体逐项对应原总装的 76 个 occurrence；
数量差 4 来自四个“小腿”实例各导入为两个实体，而不是丢件或重复装配。

从实体圆柱面直接恢复的轴心为 A/B/C/D/E，并反算得到：

```text
l1 = 49.9999999997 mm
l2 = 104.9999999997 mm
l3 = 104.9999999992 mm
l4 = 49.9999999996 mm
l5 = 60.0000000000 mm
```

这同时验证了中性 CAD、Phase 1--3 几何和坐标映射确实是同一副机构。保存姿态
约为 `l0=77.9531 mm`、`phi0=90.7237 deg`；扫描时不沿用这一轻微偏斜姿态，
而是把所有刚体放到 Phase 3 的严格中心竖直路径。

同时冻结的 Parasolid 37.1 文本导出 SHA-256 为：

```text
b439fc9bc335800fb499c121d606e23b7612285c394d0771d47cf28113991a82
```

当前 Linux 开源几何链不能直接读取该 Parasolid，因此它只作为第二份源文件
指纹保留，碰撞结论来自通过完整实体资格检查的 AP214，不是假装做了双内核
交叉验证。

EduLite 使用 RobStride 官方 18-solid STEP，SHA-256 为
`3c970be5...9e27ee3`。官方说明书和 STEP 一致给出主体直径 `46 mm`、主体长度
`44 mm`、输出侧约 `3 mm` 凸出；完整商品实体（含凸出件）的包围盒约为
`49.704 x 49.619 x 47.000 mm`。原 4010 总装实体的轴向厚度仅 `25.5 mm`，
这解释了为什么两者径向尺寸接近，轴向内部包装却不能直接沿用。

## 扫描方法及其边界

每个姿态直接调用 Phase 3 的正常 outward-elbow 解析分支。A/E 固定，四组
主动短杆、从动长杆和轮系按对应轴心做刚体变换；每个代表性杆件的圆柱轴在
`70/120 mm` 均以不超过 `2e-6 mm` 的误差落在目标 A/B/C/D/E 上。

碰撞检查不是二维线段或包围盒结论：包围盒只做 broad phase，最终使用精确
B-Rep `distToShape` 和候选接触对的 Boolean common volume。输出保留具体实体
名、腿长、最小距离和新增公共体积。

转轴、轴承、螺栓/孔等设计接触不能直接当碰撞，也不能整组忽略。本次把总装
保存姿态的相邻实体公共体积作为关节基线，在新姿态中只把增加的公共体积判为
干涉。这一检查正是发现短端主动杆/小腿互穿的关键。原总装保存姿态的这些
相邻对没有正公共体积，因此短端结果不是“减掉太多”得到的假阴性。

原结构 `70--120 mm` 和 `47--70 mm` 使用 1 mm 扫描；长端 `121--152 mm`
使用 2 mm 扫描并额外检查 152 mm。干涉退出边界细分到 0.1 mm，接触退出
边界细分到 0.01 mm。因而 `60.4/60.5` 和 `67.70/67.71 mm` 应理解为最后/第一
个已检查样本组成的边界区间，不是假精度的解析硬限位。

## 原结构的机械限制来自哪里

`l0=47 mm` 时，最大新增交叠约 `1039.54 mm³`，限制对为右侧
`大腿垫高001 / 小腿010`；左侧镜像对也约为 `1015.24 mm³`。到
`l0=60.4 mm` 最大交叠已降至 `0.602 mm³`，`60.5 mm` 的公共体积为零。

随后机构仍不能视为可用：4010 电机端面与小腿端面处于零轴向间隙，只要它们
在 Y-Z 投影重叠，精确实体距离就是零。`67.70 mm` 仍接触；`67.71 mm` 虽为
正距离，但只有约 25 nm。间隙随后快速增加：

| `l0` | 最小间隙 | 限制实体 |
|---:|---:|---|
| 68 mm | 0.0259 mm | 4010 电机 / 小腿 |
| 69 mm | 0.4010 mm | 4010 电机 / 小腿 |
| 70 mm | 0.9849 mm | 4010 电机 / 小腿 |
| 108--116 mm | 约 1.4430 mm | 底板 / 随小腿运动的 M4x16 螺钉 |
| 120 mm | 1.8534 mm | 底板 / M4x16 螺钉 |
| 152 mm | 7.0473 mm | 底板 / 小腿实体 |

这确认了 `70 mm` 不是 CAD 硬止挡，而是一个接近 1 mm 名义间隙的控制下界。
STEP 没有制造公差、装配偏心、轴承游隙、受力挠曲或线束，因此本阶段不能把
`0.985 mm` 升级成实物安全余量。相反，它提示单侧腿台架必须实测 70 mm 附近
的间隙，并在最终图纸上做公差叠加。

## EduLite 的机械判定

替换检查把四个 EL05 输出轴与原 A/E 同轴，并把官方图纸的输出安装面放在原
4010 输出面 `x=+/-66.5 mm`。这是一项可复核的包装假设，不是任意平移寻找
“能放进去”的乐观姿态。

保留原机身内部器件时，EL05 后部侵入原 NanoPi 支架、电池架和支撑铜柱；
这些冲突与 `l0` 无关，所以整段行程都不能称为 CLEAR。另一方面，清除明确
需要重新设计/重排的包装实体后，官方 EL05 商品外形与底板和运动腿系在
`70--120 mm` 全段没有碰撞，最小间隙约 `0.915 mm`，仍发生在 70 mm 的
EL05/小腿之间。

原主动杆接口也不能直接复用：EL05 输出侧凸出和紧固件与原主动杆孔区在保存
姿态存在交叠。这不是运动中随机撞击，而是安装接口几何不匹配，必须由新输出
法兰/主动杆端部定义解决。因此当前能够可靠说的是：EL05 的商品外形没有迫使
我们放弃 70--120 mm 或修改杆长，但需要真实的关节安装设计和内部布局重排。

## 工程决策与下一证据门

| 决策 | 判定 | 证据层级 |
|---|---|---|
| 原 `50/105/105/50/60 mm` 杆长 | KEEP | 原 CAD 70--120 mm 无干涉，且 Phase 3 运动学优秀 |
| 原结构 70--120 mm 进入后续动力分析 | KEEP | 已证明（当前 CAD/1 mm 扫描） |
| 把 46.1--152.1 mm 当实际行程 | REJECT | 短端实体干涉，长端数学奇异 |
| EduLite 05 作为候选商品执行器 | CONDITIONAL KEEP | 腿系商品外形必要条件通过 |
| EduLite 原位直装 | REJECT | 原支架、接口和内部包装明确冲突 |
| EduLite 替换后最终机械行程 | UNKNOWN | 新支架、主动杆接口、器件重排和线束尚无 CAD |
| 现在进入 150 mm 台阶动力学 | NOT YET | 最终执行器集成几何尚未闭合 |

下一笔最值得投入的机械工作已经很具体：建立一套最小但真实可制造的 EL05
关节安装 CAD，明确输出法兰/主动杆连接、壳体支撑、轴向层叠，并重新布置当前
发生冲突的 NanoPi/电池支撑；随后把线束 keep-out 加入同一 70--120 mm 扫描。
这一步完成后才能把“必要条件通过”升级为“EduLite 集成 CLEAR”，并把真实
行程作为执行器匹配和整机动力学的输入。继续做全局 Jacobian 或修改杆长不会
减少当前这个不确定性。

## 复现

输入指纹和姿态表：

```bash
python3 scripts/prepare_mechanical_envelope.py \
  --upstream-dir .worktrees/upstream-reference \
  --original-step /path/to/foc-wheel-legged-robot_full_assembly_AP214.step \
  --original-parasolid /path/to/foc-wheel-legged-robot_full_assembly.x_t \
  --edulite-step /path/to/el05.stp \
  --edulite-manual /path/to/EL05使用说明书260713.pdf
```

原结构 baseline 扫描在 FreeCAD 中运行：

```bash
CAD_STEP_PATH=/path/to/full_assembly_AP214.step \
CAD_OUTPUT_DIR=artifacts/mechanical_envelope/original_cad_70_120_verified \
CAD_START_MM=70 CAD_STOP_MM=120 CAD_STEP_MM=1 \
CAD_CLASSIFY_CONTACT_VOLUME=1 CAD_CHECK_ADJACENT_EXCESS=1 \
freecad.cmd scripts/analyze_mechanical_envelope_freecad.FCMacro
```

详细结果位于 `artifacts/mechanical_envelope/`；`pose_summary.csv` 给出每个姿态
的判定和限制对，`pair_events.csv` 保留近邻实体距离/公共体积，`cad_audit.json`
记录输入、恢复几何、刚体分组和扫描配置。
